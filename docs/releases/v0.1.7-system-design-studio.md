# Release Notes — v0.1.7-system-design-studio

**Release Date**: August 24, 2026  
**Status**: Stable / Production Ready  
**Version**: `v0.1.7-system-design-studio`

---

## 1. Objective

Phase 9 introduces the **System Design Studio & Interactive Diagramming** layer for ArchitectAI. Authenticated repository owners can now automatically derive C4-style architecture diagrams (System Context, Container, Component views) from existing PostgreSQL knowledge graph nodes and architecture analysis data, interactively explore, drag, filter, and export system designs to JSON/SVG format, and query architecture details via grounded RAG assistant prompts.

---

## 2. Database Schema Extensions

- **Enums**:
  - `DiagramType`: `SYSTEM_CONTEXT`, `CONTAINER`, `COMPONENT`.
  - `DiagramNodeType`: `PERSON`, `SYSTEM`, `CONTAINER`, `COMPONENT`, `DATABASE`, `EXTERNAL_SYSTEM`, `API`, `SERVICE`, `MODULE`.
  - `DiagramEdgeType`: `USES`, `CALLS`, `DEPENDS_ON`, `CONTAINS`, `READS`, `WRITES`, `EXPOSES`, `IMPORTS`.
- **`SystemDesign` Model**: `id`, `repositoryId`, `name`, `description`, `version`, `generatedAt`, `metadata`, `createdAt`, `updatedAt`.
  - Foreign key relation to `Repository` (`onDelete: Cascade`), `Diagram[]` (`onDelete: Cascade`).
- **`Diagram` Model**: `id`, `systemDesignId`, `type`, `name`, `description`, `metadata`, `createdAt`, `updatedAt`.
  - Composite unique constraint `[systemDesignId, type]`.
- **`DiagramNode` Model**: `id`, `diagramId`, `graphNodeId` (nullable), `type`, `name`, `label`, `description`, `x`, `y`, `width`, `height`, `metadata`, `createdAt`, `updatedAt`.
  - Composite unique constraint `[diagramId, name]`.
- **`DiagramEdge` Model**: `id`, `diagramId`, `sourceNodeId`, `targetNodeId`, `type`, `label`, `metadata`, `createdAt`, `updatedAt`.
  - Composite unique constraint `[diagramId, sourceNodeId, targetNodeId, type]`.
- **Migration**: Applied `20260824155728_add_system_design_studio`.

---

## 3. Core Services

- **`SystemDesignDiscoveryService`**: Maps `GraphNode` and `GraphEdge` structures into C4 elements (`PERSON`, `SYSTEM`, `CONTAINER`, `COMPONENT`, `DATABASE`, `EXTERNAL_SYSTEM`).
- **`DiagramGenerationService`**: Generates C4 System Context, Container, and Component diagram representations with evidence trails pointing back to Knowledge Graph nodes and repository files.
- **`DiagramLayoutService`**: Computes deterministic x/y node coordinates for initial canvas placement and preserves custom node position updates.
- **`SystemDesignService`**: Main orchestrator managing Redis concurrency locking (`system-design:generate-lock:<repositoryId>`, TTL 600s, `EX 600 NX`), versioning, position updates, reset layout, and cascade deletion.
- **`SystemDesignContextService`**: Injects C4 system design context into the Phase 7 RAG assistant pipeline.

---

## 4. REST APIs

- `GET /api/v1/repositories/:id/system-design` — Get latest system design summary.
- `POST /api/v1/repositories/:id/system-design/generate` — Generate or regenerate C4 diagrams (returns 409 if locked).
- `GET /api/v1/repositories/:id/system-design/diagrams` — List all diagrams.
- `GET /api/v1/repositories/:id/system-design/diagrams/:diagramId` — Get complete diagram detail.
- `PATCH /api/v1/repositories/:id/system-design/diagrams/:diagramId/nodes/:nodeId` — Update node x/y position.
- `POST /api/v1/repositories/:id/system-design/diagrams/:diagramId/reset-layout` — Reset layout coordinates.
- `DELETE /api/v1/repositories/:id/system-design` — Delete system design.

## 5. Frontend System Design Studio Interface

- **`SystemDesignOverview`**: Top header displaying design version, generated views count, and timestamp.
- **`DiagramTypeSelector`**: Tab selector for System Context, Container, and Component views.
- **`DiagramToolbar`**: Toolbar offering reset layout trigger, C4 legend toggle, and export drop-down.
- **`DiagramCanvas`**: Interactive SVG canvas displaying diagram nodes, edge arrows, and relationship labels.
- **`DiagramNodeDetails`**: Slide-over drawer displaying node type, role, description, source path, and Knowledge Graph ID.
- **`DiagramFilters`**: Dropdown filter for filtering canvas nodes by type.
- **`SystemDesignExportButton`**: Exports active diagram as JSON or SVG image files.
- Integrated into `/repositories/[id]` page as **"System Design 📐"** tab.
