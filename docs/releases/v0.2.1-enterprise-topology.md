# Release Notes — v0.2.1-enterprise-topology

**Release Date**: August 24, 2026  
**Status**: Stable / Production Ready  
**Version**: `v0.2.1-enterprise-topology`

---

## 1. Objective

Phase 13 transforms ArchitectAI from a single-repository intelligence engine into a **Multi-Repository Architecture Federation & Enterprise Topology Platform**. Users can now register multi-repository enterprise systems, discover cross-service dependencies, visualize enterprise topology graphs, detect cross-boundary architectural violations, calculate deterministic enterprise risk scores, and query topology intelligence via Phase 7 RAG.

Crucially, Phase 13 **preserves all repository-level capabilities** from Phases 1–12 and maintains the strict **Human Approval Boundary** from Phase 12.

---

## 2. Key Features & Highlights

### Database Architecture

- Created `EnterpriseSystem`, `RepositoryDependency`, `EnterpriseTopologyAnalysis`, and `EnterpriseTopologyFinding` Prisma models with migration `20260824164145_add_enterprise_topology_federation`.
- Extended `Repository` model with `enterpriseSystemId` and `role` (`FRONTEND`, `BACKEND`, `SERVICE`, `LIBRARY`, `DATABASE`, `INFRASTRUCTURE`, `MOBILE`, `SHARED`, `UNKNOWN`).

### Enterprise System Management

- `EnterpriseSystemService`: System registration, listing, role assignments, repository membership management, and multi-tenant IDOR protection.

### Inter-Repository Dependency Discovery

- `TopologyDiscoveryService`: Automatically infers dependencies (`RepositoryDependencyType`: `IMPORTS`, `HTTP_CALL`, `API_DEPENDENCY`, `SHARED_LIBRARY`, `DATABASE_DEPENDENCY`, `EVENT_DEPENDENCY`, `CONFIG_DEPENDENCY`, `UNKNOWN`) and assigns confidence levels (`HIGH`, `MEDIUM`, `LOW`) using evidence from package manifests, import files, Docker configs, and GraphNodes.

### Enterprise Topology Audit & Risk Scoring

- `TopologyAuditorService`: Detects cross-repository cycles (`CIRCULAR_SERVICE_DEPENDENCY`), high coupling, single points of failure (`SINGLE_POINT_OF_FAILURE`), shared library hotspots (`SHARED_LIBRARY_HOTSPOT`), and cross-boundary violations (e.g. Frontend directly contacting DB repo).
- `TopologyRiskService`: Calculates deterministic enterprise risk scores (0–100) and risk levels (`LOW`, `MODERATE`, `ELEVATED`, `HIGH`, `CRITICAL`) with factor penalties breakdown without external LLM scoring.

### Concurrency & Locking

- `TopologyAnalysisService`: Handles analysis orchestration protected by Redis locking (`enterprise-topology-lock:<enterpriseSystemId>`, 600s TTL, `EX 600 NX`). Returns HTTP 409 Conflict if active.

### Phase 7 RAG & UI Integration

- `TopologyContextService`: Integrates enterprise topology intelligence into Phase 7 RAG assistant queries (`"enterprise"`, `"topology"`, `"microservice"`, `"cross-repository"`, `"dependencies"`).
- Frontend Enterprise Topology: Added `/systems/[id]` detail page and `EnterpriseSystemOverview`, `TopologyGraph`, `TopologyRiskScore`, `TopologyRepositories`, `TopologyDependencies`, `TopologyFindings`, `TopologyHistory`, and `DependencyConfidenceBadge` components.
