## 1. Objective

Phase 7 introduces the **AI Repository Understanding / RAG Foundation** for ArchitectAI. Authenticated users can now ask natural-language architectural questions about connected GitHub repositories and receive grounded responses backed by retrieved repository context and explicit source citations.

---

## 2. Database Schema Extensions

- **`MessageRole` Enum**: `USER`, `ASSISTANT`.
- **`Conversation` Model**: `id`, `userId`, `repositoryId`, `title`, `createdAt`, `updatedAt`.
  - Foreign key relations to `User` and `Repository` with `onDelete: Cascade`.
  - Indexes on `userId` and `repositoryId`.
- **`ConversationMessage` Model**: `id`, `conversationId`, `role`, `content`, `metadata`, `createdAt`.
  - Foreign key relation to `Conversation` with `onDelete: Cascade`.
  - Index on `conversationId`.
- **Migration**: Applied `20260824151754_add_ai_rag_foundation`.

## 3. RAG Intelligence Architecture

- **`ILLMProvider` & `MockLLMProviderService`**: Offline, deterministic LLM provider abstraction for zero API-key local development and automated testing.
- **`LLMProviderFactory`**: Dynamic provider resolver based on `LLM_PROVIDER` environment variable (default: `mock`).
- **`QueryUnderstandingService`**: Natural-language query parser categorizing intent (`architecture`, `security`, `general`) and extracting keywords and target node/edge types.
- **`ContextRetrieverService`**: Combines `SemanticSearchService` and `KnowledgeGraphService` to retrieve relevant file snippets and graph relationships.
- **`ContextRankerService`**: Multi-signal weighting model (Semantic similarity: 60%, Graph relevance: 25%, Lexical match: 15%) with chunk deduplication.
- **`ContextBuilderService`**: Compiles bounded context blocks enforcing `MAX_CONTEXT_CHARS` (default: `8000`), formats source reference metadata, and generates prompt-injection-safe system prompts that treat repository code strictly as untrusted DATA.
- **`ConversationService`**: Manages persistent chat conversations with user and repository ownership isolation.
- **`RagService`**: Primary RAG orchestrator enforcing ownership, acquiring Redis concurrency lock (`repository:ai-lock:<repo>:<user>`, TTL 60s, `EX 60 NX`), retrieving context, calling LLM provider, persisting messages, and returning grounded answers.

## 4. REST APIs

- `POST /api/v1/repositories/:id/ai/chat` — Submit query to AI assistant and receive grounded answer + sources.
- `GET /api/v1/repositories/:id/ai/conversations` — List repository conversations for current user.
- `GET /api/v1/repositories/:id/ai/conversations/:conversationId` — Get conversation message history.
- `DELETE /api/v1/repositories/:id/ai/conversations/:conversationId` — Delete a conversation.

---

## 5. Frontend AI Assistant

- **`AIChat`**: Main chat interface container managing conversation history, loading indicators, and error banners.
- **`AIMessage`**: Message bubble component distinguishing user and assistant messages with source citations.
- **`AISourceList`**: Expandable source citations list displaying file paths, relevance percentages, and retrieval reasons (`Vector`, `Graph + Vector`).
- **`AIChatInput`**: Input area featuring quick prompt pills and submission handling.
- **`ConversationList`**: Sidebar drawer for selecting and deleting previous repository chat sessions.
- Embedded as **"AI Assistant ✨"** tab inside `/repositories/[id]` page with dark/light mode support.
