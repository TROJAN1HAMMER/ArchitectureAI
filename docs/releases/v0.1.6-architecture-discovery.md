# Release Notes — v0.1.6-architecture-discovery

**Release Date**: August 24, 2026  
**Status**: Stable / Production Ready  
**Version**: `v0.1.6-architecture-discovery`

---

## 1. Objective

Phase 8 introduces the **Architecture Discovery & Auditing Foundation** for ArchitectAI. Authenticated repository owners can now run automated structural audits over connected codebases to discover logical components, detect cycles and boundary violations, compute a 0–100 deterministic risk score, and query findings using grounded RAG assistant questions.

## 2. Database Schema Extensions

- **Enums**:
  - `ArchitectureFindingSeverity`: `INFO`, `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`.
  - `ArchitectureFindingType`: `CIRCULAR_DEPENDENCY`, `HIGH_COUPLING`, `ARCHITECTURAL_DRIFT`, `BOUNDARY_VIOLATION`, `ORPHAN_COMPONENT`, `LARGE_COMPONENT`, `DEPENDENCY_HOTSPOT`, `DUPLICATE_STRUCTURE`, `PATTERN_DETECTED`, `RISKY_DEPENDENCY`.
  - `ArchitectureAnalysisStatus`: `PENDING`, `RUNNING`, `SUCCESS`, `FAILED`.
- **`ArchitectureAnalysis` Model**: `id`, `repositoryId`, `status`, `startedAt`, `completedAt`, `errorMessage`, `nodesAnalyzed`, `edgesAnalyzed`, `findingsGenerated`, `riskScore`, `riskLevel`, `metadata`, `createdAt`, `updatedAt`.
  - Cascade deletion on `Repository`.
  - Indexes on `repositoryId` and `status`.
- **`ArchitectureFinding` Model**: `id`, `analysisId`, `repositoryId`, `type`, `severity`, `title`, `description`, `confidence`, `sourceNodeId` (nullable), `targetNodeId` (nullable), `evidence` (JSON), `metadata` (JSON), `createdAt`.
  - Foreign key relations to `ArchitectureAnalysis`, `Repository`, and optional source/target `GraphNode` records.
  - Composite unique constraint `[analysisId, type, title, sourceNodeId, targetNodeId]`.
  - Indexes on `analysisId`, `repositoryId`, `type`, `severity`.
- **Migration**: Applied `20260824153232_add_architecture_discovery_auditing`.

## 3. Architecture Engine Services

- **`ArchitectureDiscoveryService`**: Maps `GraphNode` and `GraphEdge` paths into logical architectural components (`frontend`, `service`, `api`, `database`, `shared`, `tests`).
- **`ArchitectureAuditorService`**: Executes deterministic structural checks:
  - Tarjan's/DFS algorithm for cycle detection (`CIRCULAR_DEPENDENCY`).
  - Dynamic threshold coupling analysis (`HIGH_COUPLING`, `DEPENDENCY_HOTSPOT`).
  - Boundary violation checks (`BOUNDARY_VIOLATION`, e.g. frontend importing backend internals).
  - Orphan and oversized module detection (`ORPHAN_COMPONENT`, `LARGE_COMPONENT`).
- **`ArchitecturePatternService`**: Identifies evidence-backed structural patterns (`Modular Monolith`, `Service Layer Pattern`, `REST API Gateway`, `Component-Based Frontend`).
- **`ArchitectureRiskService`**: Computes an explainable weighted risk score (0–100) and risk level (`LOW`, `MODERATE`, `ELEVATED`, `HIGH`, `CRITICAL`).
- **`ArchitectureAnalysisService`**: Main orchestrator handling Redis concurrency locking (`repository:architecture-lock:<repositoryId>`, 600s TTL, `EX 600 NX`), ownership validation, execution, and idempotent findings persistence.
- **`ArchitectureContextService`**: Injects architecture analysis summaries into the Phase 7 RAG pipeline so questions like "Why is the architecture risky?" produce cited evidence.

## 4. REST APIs

- `GET /api/v1/repositories/:id/architecture` — Fetch latest architecture analysis summary.
- `POST /api/v1/repositories/:id/architecture/analyze` — Trigger background analysis (returns HTTP 409 Conflict if locked).
- `GET /api/v1/repositories/:id/architecture/findings` — List filterable findings (by `type`, `severity`, with `limit` and `offset`).
- `GET /api/v1/repositories/:id/architecture/findings/:findingId` — Fetch detailed finding evidence.
- `GET /api/v1/repositories/:id/architecture/components` — List discovered logical components.
- `GET /api/v1/repositories/:id/architecture/history` — Fetch previous analysis run history.

## 5. Frontend Architecture Interface

- **`ArchitectureOverview`**: Top-level summary grid displaying risk score, node counts, edge counts, and finding totals.
- **`ArchitectureRiskScore`**: Gauge indicator displaying score (0–100), risk level badge, and primary risk contributors.
- **`ArchitectureFindings`**: Filterable findings table with severity badges and detail trigger.
- **`ArchitectureComponents`**: Discovered component cards displaying node counts, file counts, and inbound/outbound dependencies.
- **`ArchitecturePatterns`**: Detected pattern cards displaying confidence percentages and evidence.
- **`ArchitectureAnalysisButton`**: Manual trigger button managing background loading states.
- **`ArchitectureHistory`**: History list of past analysis runs.
- **`ArchitectureFindingDetail`**: Slide-over modal displaying description, affected paths, and raw JSON evidence.
- Integrated into `/repositories/[id]` page as **"Architecture Audit 🛡️"** tab.
